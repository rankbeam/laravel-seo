# Запуск демоприложения {#run-the-demo}

Самый быстрый способ увидеть Rankbeam на настоящих страницах, не подключая его сначала к своему приложению, — готовое к запуску демо. Это приложение Laravel с демонстрационными данными, которое устанавливает **выпущенные** пакеты (без path-репозиториев и соседних рабочих копий) и выводит несколько страниц с полными SEO-метаданными, графом schema.org в JSON-LD и картой сайта. Добавьте лицензию, и оно также выполнит [технический SEO-аудит](/ru/pro/scan-issues) Pro.

## Одна команда (бесплатное ядро) {#one-command-free-core}

Демо поставляется как Docker-образ в репозитории [`rankbeam-examples`](https://github.com/rankbeam/rankbeam-examples):

```bash
git clone https://github.com/rankbeam/rankbeam-examples
cd rankbeam-examples/demo
docker compose up --build
```

Откройте `http://localhost:8080`. Посмотрите исходный код любой страницы, чтобы увидеть итоговый `<head>`, а созданную карту сайта — по адресу `/sitemap.xml`. Всё здесь использует бесплатное ядро под MIT, установленное из Packagist.

## С Pro (аудит) {#with-pro-the-audit}

Pro лицензируется для проекта и устанавливается из закрытого репозитория Composer. Передайте лицензию через `COMPOSER_AUTH` (секрет сборки, который никогда не записывается в слой образа) и соберите с флагом Pro:

```bash
export COMPOSER_AUTH='{"http-basic":{"blog.rankbeam.dev":{"username":"you@example.com","password":"YOUR-LICENSE-KEY"}}}'
WITH_PRO=true docker compose up --build
```

При старте демо выполняет [`seo:doctor`](/ru/pro/headless#setup-health-check) и первый `seo-pro:scan` по демонстрационным страницам. Отчёт состояния, сводка сканирования и [оценка 0–100](/ru/pro/scoring) выводятся в журналы compose.

## Посмотрите рабочий процесс Pro {#see-the-pro-workflow}

[Пошаговый пример сканирование → исправление → отчёт](/ru/pro/walkthrough) показывает работающий Merchant: настоящее сканирование, детали проблемы, сохранённое описание в Filament, повторное сканирование и PDF для скачивания. Контент обозначен как демонстрационный, а результаты до/после получены двумя новыми сканированиями.

Публичного размещённого интерактивного демо пока нет. Запустите движок локально через Docker; [README демо](https://github.com/rankbeam/rankbeam-examples/tree/main/demo) описывает настройку и переключение между выпущенными и локальными пакетами.
