# Установка Pro {#installing-pro}

`rankbeam/laravel-seo-pro` добавляет к ядру сканирование сайта через очередь с отслеживанием проблем, менеджер перенаправлений и монитор 404. Движок работает в **любом приложении Laravel 11–13** — Blade, Inertia или чистом API. Filament — необязательный слой интерфейса: установите его, чтобы получить SEO-панель, менеджер перенаправлений и монитор 404 как страницы панели, или управляйте всем через [команды artisan](/ru/pro/headless).

## Требования {#requirements}

| | |
|---|---|
| PHP | 8.2–8.4 (Laravel 11); 8.2–8.5 (Laravel 12); 8.3–8.5 (Laravel 13) |
| Laravel | 11, 12 или 13 |
| `rankbeam/laravel-seo` | ^3.20 (устанавливается автоматически с Pro 2.40+) |
| `filament/filament` | **Необязательно** — 4.x или 5.x, только для интерфейса администратора |
| `rankbeam/laravel-seo-filament` | **Необязательно** — ^1.11 при использовании SEO-редактора с Pro 2.36+ |

Начните с существующего приложения Laravel с настроенной базой данных. Сначала выполните [быстрый старт ядра](/ru/guide/quickstart), чтобы модель выводила метаданные и таблицы ядра уже существовали. Лицензия Pro предоставляет указанные ниже учётные данные Composer.

Наглядный пример результата — [сканирование → исправление → отчёт](/ru/pro/walkthrough).

## Установка пакета {#install-the-package}

Pro распространяется через закрытый репозиторий Composer, связанный с вашей лицензией. Один раз добавьте репозиторий, затем установите пакет: Composer запросит email лицензии (имя пользователя) и лицензионный ключ (пароль):

Lemon Squeezy принимает оплату как официальный продавец. После оплаты на закрытой странице квитанции доступны ключ загрузки и инструкции Composer. В качестве имени пользователя используйте email покупки. Репозиторий пакета размещает Rankbeam; учётная запись Anystack не нужна. Не раскрывайте ссылку на квитанцию и `auth.json`. Полный возврат средств отзывает доступ к последующим загрузкам и обновлениям, не прерывая работу установленного приложения.

```bash
composer config repositories.rankbeam-pro composer https://blog.rankbeam.dev/composer
composer require rankbeam/laravel-seo-pro
```

::: details Неинтерактивная аутентификация Composer
Для CI и других неинтерактивных окружений заранее сохраните учётные данные:

```bash
composer config http-basic.blog.rankbeam.dev you@example.com YOUR-LICENSE-KEY
```

:::

Затем запустите установщик:

```bash
php artisan seo-pro:install
```

Установщик публикует `config/seo-pro.php` и миграции Pro, выполняет `migrate` и выводит дальнейшие шаги. Теперь в базе приложения должны присутствовать таблицы ядра и Pro.

::: details Ручная установка и параметры установщика
Миграции Pro публикуются в приложение, а не загружаются автоматически из пакета. Эквивалентные ручные шаги:

```bash
php artisan vendor:publish --tag=seo-pro-config
php artisan vendor:publish --tag=seo-pro-migrations
php artisan migrate
```

Установщик можно запускать повторно. `--no-migrate` публикует файлы без выполнения миграций. Используйте `--force`, только если намерены перезаписать опубликованные файлы, включая свою конфигурацию.
:::

## Регистрация целей сканирования {#register-scan-targets}

В сервис-провайдере укажите, что сканировать: классы моделей, именованные маршруты или всё из [реестра карт сайта](/ru/guide/sitemaps):

```php
use App\Models\Post;
use Rankbeam\Seo\Pro\Facades\SeoPro;

public function boot(): void
{
    SeoPro::targets()->register('posts', Post::class);
    // Optional: register named routes that exist in your app.
    // SeoPro::targets()->registerRoutes('static', ['home', 'pricing']);
    // Or discover targets from your registered sitemaps:
    // SeoPro::targets()->fromSitemaps();
}
```

Замените `Post` своей моделью с `HasSEO`. Для результата сканирования модели нужна хотя бы одна запись. Цели-маршруты должны ссылаться на существующие имена маршрутов; не добавляйте эту регистрацию, если хотите сканировать только модели.

## Проверка установки {#verify-your-install}

Запустите проверку конфигурации:

```bash
php artisan seo:doctor
```

Убедитесь, что таблицы ядра и Pro существуют, URL приложения задан верно, а цели сканирования перечислены. Выполните предложенные исправления. Предупреждение об очереди `sync` ожидаемо, пока вы пробуете синхронные команды ниже; перед планированием сканирований рабочего сайта настройте воркер.

`seo:doctor` проверяет конфигурацию и историю недавних запусков без сетевых запросов и вывода секретов. Команда не может доказать, что внешний cron или воркер действительно работает. Критические ошибки возвращают ненулевой код завершения, предупреждения — нет. Для машиночитаемого результата используйте `--json`.

## Первое сканирование {#five-minute-pro-tour}

```bash
php artisan seo-pro:scan --sync
php artisan seo-pro:scan-status
```

Первая команда выполняет сканирование синхронно, поэтому для этой первоначальной проверки воркер очереди не нужен. Вторая показывает последний запуск и его результаты. Ожидайте завершённый запуск с обработанными зарегистрированными целями; разберитесь с ошибками отдельных целей, прежде чем считать сканирование завершённым.

Исправьте одно отмеченное поле, сохраните его и запустите сканирование повторно. [Пошаговый пример](/ru/pro/walkthrough) показывает это для отсутствующего описания и отчёта об изменении. [Техническая оценка](/ru/pro/scoring) — результат диагностики, а не прогноз позиций.

## Работа без интерфейса {#path-b-headless}

Движок готов к работе без панели. [Команды artisan](/ru/pro/headless) позволяют сканировать, изучать проблемы, создавать перенаправления и отчёты. Middleware перенаправлений и 404 по умолчанию регистрируются автоматически; их настройки находятся в `config/seo-pro.php`.

Для работы по расписанию настройте очереди, воркеры, планировщик и сроки хранения по [руководству для рабочего окружения](/ru/pro/production).

## Добавление панели Filament (необязательно) {#path-a-with-a-filament-panel}

В существующей панели Filament 4 или 5 зарегистрируйте плагин Pro, как показано ниже. Если панели ещё нет, сначала установите пакеты интерфейса и создайте её:

```bash
composer require filament/filament rankbeam/laravel-seo-filament
php artisan filament:install --panels
php artisan make:filament-user
```

```php
use Rankbeam\Seo\Pro\Filament\SeoProPlugin;

public function panel(Panel $panel): Panel
{
    return $panel
        // ...
        ->plugin(SeoProPlugin::make());
}
```

Это добавляет **SEO-панель** (действие сканирования всех целей, ход выполнения в реальном времени, список проблем с повторным сканированием одним нажатием), **менеджер перенаправлений** и **монитор 404** с действием *создания перенаправления* одним нажатием. `rankbeam/laravel-seo-filament` также добавляет [раздел SEO-полей](/ru/guide/filament) в формы ресурсов.

## Устранение неполадок {#troubleshooting}

| Результат | Следующий шаг |
|---|---|
| Composer отклоняет учётные данные | Проверьте email лицензии и ключ для `blog.rankbeam.dev`. Не сохраняйте учётные данные в системе контроля версий. |
| Doctor сообщает об отсутствующих таблицах | Выполните быстрый старт ядра, затем `seo-pro:install` и `migrate` для той же базы, которую использует приложение. |
| Сканирование не обрабатывает ни одной цели | Проверьте регистрацию в провайдере и наличие записей модели. |
| Сканирование в очереди остаётся в ожидании | Запустите настроенный воркер очереди или используйте `--sync` для синхронной проверки. |
| Цель завершилась с ошибкой | До повторного сканирования проверьте детали запуска, имена маршрутов и URL приложения. |
| Панель отсутствует | Зарегистрируйте `SeoProPlugin` в действительно используемой панели и проверьте правила доступа. |

Восстановление воркеров и повседневная эксплуатация описаны в [настройке рабочего окружения](/ru/pro/production).
