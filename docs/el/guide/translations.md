# Μεταφράσεις {#translations}

Κάθε κείμενο που εμφανίζουν τα πακέτα στον χρήστη — ευρήματα ελέγχου, ζωντανές προειδοποιήσεις επεξεργαστή κάτω από
τα πεδία Filament, ετικέτες, προεπισκοπήσεις, αναφορές — είναι γραμμή γλώσσας Laravel. Τα πακέτα
ακολουθούν το `app()->getLocale()`: ένα περιβάλλον διαχείρισης που λειτουργεί στα ιταλικά εμφανίζει ιταλικά χωρίς καμία ρύθμιση.

Οι **κωδικοί** ζητημάτων και προειδοποιήσεων (`missing_title`, `title_too_long`, …) δεν αλλάζουν και δεν
μεταφράζονται ποτέ. Μεταφράζεται μόνο η πρόταση που συνοδεύει τον κωδικό.

Περιλαμβανόμενες γλώσσες: αγγλικά, ιταλικά (τα προηγούμενα κείμενα έχουν ελεγχθεί· τα αλλαγμένα χρειάζονται νέο έλεγχο) και πρώτες μεταφράσεις στα γερμανικά, γαλλικά, ισπανικά,
πορτογαλικά Βραζιλίας, ολλανδικά, τουρκικά, ρωσικά, πολωνικά (Επίπεδο 1) και, από τον πυρήνα 3.16 / Filament
1.10 / Pro 2.35, ιαπωνικά, απλοποιημένα κινεζικά (`zh_CN`), παραδοσιακά κινεζικά (`zh_TW`), κορεατικά,
ελληνικά, ουκρανικά και τσεχικά (Επίπεδο 2). Η ακριβής κατάσταση ανά locale βρίσκεται στο
[TRANSLATING.md](https://github.com/rankbeam/laravel-seo/blob/master/TRANSLATING.md)· ο έλεγχος από
φυσικό ομιλητή είναι αυτός που μετατρέπει μια πρώτη μετάφραση σε υποστηριζόμενη γλώσσα.

## Παράκαμψη ενός κειμένου {#override-a-string}

```bash
php artisan vendor:publish --tag=seo-lang            # core (3.13+)
php artisan vendor:publish --tag=seo-filament-lang   # Filament fields (1.6+)
php artisan vendor:publish --tag=seo-pro-lang        # Pro (2.31+)
```

Έπειτα επεξεργαστείτε το `lang/vendor/seo/{locale}/seo.php` (και τους διπλανούς φακέλους για τα άλλα
πακέτα). Τα κλειδιά που κρατάτε παρακάμπτουν τα αρχικά· τα υπόλοιπα χρησιμοποιούν το αρχείο του πακέτου και έπειτα τα
αγγλικά.

## Συνεισφορά μιας γλώσσας {#contribute-a-language}

Αντιγράψτε το αρχείο `en` στο locale σας, μεταφράστε τις τιμές, κρατήστε κάθε `:placeholder`, εκτελέστε τη
σουίτα (η δοκιμή αντιστοιχίας αποτυγχάνει για κάθε κλειδί που λείπει, ορφανό κλειδί, κενή τιμή ή χαμένο placeholder)
και ανοίξτε ένα pull request. Οι πλήρεις κανόνες και το γλωσσάρι βρίσκονται στο
[TRANSLATING.md](https://github.com/rankbeam/laravel-seo/blob/master/TRANSLATING.md).

## Τι δεν μεταφράζεται σκόπιμα {#what-is-not-translated-on-purpose}

Η παρουσίαση CLI είναι από προεπιλογή στα αγγλικά. Ορίστε `seo.cli_locale` / `SEO_CLI_LOCALE`
ή περάστε `--display-locale=it` για να μεταφράσετε τα υποστηριζόμενα μηνύματα και τις περιλήψεις ελέγχου.
Το Pro έχει δική του ρύθμιση `seo-pro.cli_locale`. Η γλώσσα εμφάνισης είναι ξεχωριστή από
το locale περιεχομένου που επιλέγεται με `--locale`.

- Η βοήθεια εντολών, τα διαγνωστικά συντήρησης και η έξοδος `seo:explain` παραμένουν στα αγγλικά· οι ετικέτες PASS/WARN/FAIL παραμένουν σταθερές.
- Αποδιδόμενο HTML (`<meta>`, JSON-LD): η γλώσσα του περιεχομένου σας, ποτέ του πακέτου.
- Οι κωδικοί ζητημάτων και τα κλειδιά JSON/οι κωδικοί κατάστασης παραμένουν σταθερά αναγνωριστικά. Οι ετικέτες για ανθρώπους στην έξοδο `--json` μπορούν να μεταφραστούν· οι ενσωματώσεις πρέπει να χρησιμοποιούν κλειδιά και κωδικούς.

## Το άλλο μισό: η γλώσσα του περιεχομένου σας {#the-other-half-your-content-s-language}

Αυτή η σελίδα αφορά τη γλώσσα που μιλά το *πακέτο*. Το πώς κατανοεί τη
γλώσσα του *περιεχομένου* σας — όρια τίτλων ανά σύστημα γραφής, περικοπή, πεζά/κεφαλαία,
πολιτικές hreflang, `inLanguage`, περιφερειακές μηχανές αναζήτησης, γραμματοσειρές εικόνων OG — καλύπτεται στο
[Πολύγλωσσο περιεχόμενο](/el/guide/multilingual).
