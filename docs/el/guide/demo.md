# Εκτέλεση της επίδειξης {#run-the-demo}

Ο ταχύτερος τρόπος να δείτε το Rankbeam να λειτουργεί σε πραγματικές σελίδες — χωρίς να το ενσωματώσετε πρώτα
στη δική σας εφαρμογή — είναι η εκτελέσιμη επίδειξη. Είναι μια εφαρμογή Laravel με αρχικά δεδομένα που
εγκαθιστά τα **δημοσιευμένα** πακέτα (χωρίς path repos, χωρίς γειτονικά checkouts) και
αποδίδει μερικές σελίδες με πλήρη μεταδεδομένα SEO, γράφο schema JSON-LD και
χάρτη ιστοτόπου. Προσθέστε άδεια και εκτελεί επίσης τον [έλεγχο τεχνικού SEO
του Pro](/el/pro/scan-issues).

## Μία εντολή (δωρεάν πυρήνας) {#one-command-free-core}

Η επίδειξη παρέχεται ως εικόνα Docker στο αποθετήριο
[`rankbeam-examples`](https://github.com/rankbeam/rankbeam-examples):

```bash
git clone https://github.com/rankbeam/rankbeam-examples
cd rankbeam-examples/demo
docker compose up --build
```

Ανοίξτε το `http://localhost:8080`. Προβάλετε τον πηγαίο κώδικα οποιασδήποτε σελίδας για να δείτε το επιλυμένο
`<head>`· επισκεφθείτε το `/sitemap.xml` για τον παραγόμενο χάρτη ιστοτόπου. Όλα εδώ ανήκουν στον
δωρεάν πυρήνα MIT, εγκατεστημένο από το Packagist.

## Με το Pro (ο έλεγχος) {#with-pro-the-audit}

Το Pro αδειοδοτείται ανά έργο και εγκαθίσταται από το ιδιωτικό αποθετήριο Composer του.
Περάστε την άδειά σας μέσω του `COMPOSER_AUTH` (μυστικό build — δεν γράφεται ποτέ σε
επίπεδο της εικόνας) και κάντε build με τη σημαία Pro:

```bash
export COMPOSER_AUTH='{"http-basic":{"blog.rankbeam.dev":{"username":"you@example.com","password":"YOUR-LICENSE-KEY"}}}'
WITH_PRO=true docker compose up --build
```

Κατά την εκκίνηση, η επίδειξη εκτελεί το [`seo:doctor`](/el/pro/headless#setup-health-check) και μια πρώτη
`seo-pro:scan` στις σελίδες με αρχικά δεδομένα — η αναφορά υγείας, η σύνοψη σάρωσης και η
[βαθμολογία 0–100](/el/pro/scoring) εκτυπώνονται στα logs του compose.

## Δείτε τη ροή εργασίας Pro {#see-the-pro-workflow}

Η [αναλυτική διαδρομή σάρωση → διόρθωση → αναφορά](/el/pro/walkthrough) δείχνει μια εκτελούμενη
επίδειξη Merchant: πραγματική σάρωση, λεπτομέρειες ζητημάτων, αποθηκευμένη περιγραφή στο
Filament, επανασάρωση και PDF προς λήψη. Το περιεχόμενό της επισημαίνεται ως ενδεικτικά
δεδομένα και τα αποτελέσματα πριν και μετά προέρχονται από δύο νέες σαρώσεις.

Δεν υπάρχει ακόμη δημόσια διαδραστική φιλοξενούμενη επίδειξη. Χρησιμοποιήστε το Docker για να εκτελέσετε τη μηχανή
τοπικά· το [README της επίδειξης](https://github.com/rankbeam/rankbeam-examples/tree/main/demo)
περιγράφει τη ρύθμιση και την εναλλαγή μεταξύ δημοσιευμένων και τοπικών πακέτων.

Παραλείψτε την επίδειξη και πηγαίνετε απευθείας στη [Γρήγορη εκκίνηση](/el/guide/quickstart) — από την εγκατάσταση
σε πλήρως αποδιδόμενο `<head>` σε πέντε λεπτά.
