# Εγκατάσταση του Pro {#installing-pro}

Το `rankbeam/laravel-seo-pro` προσθέτει σαρώσεις ιστοτόπου μέσω ουράς με παρακολούθηση ζητημάτων,
διαχείριση ανακατευθύνσεων και παρακολούθηση 404 πάνω στο πακέτο πυρήνα. Η μηχανή λειτουργεί σε **κάθε εφαρμογή Laravel 11–13** — Blade, Inertia ή καθαρό API.
Το Filament είναι προαιρετικό επίπεδο διεπαφής: εγκαταστήστε το και αποκτάτε τον πίνακα ελέγχου SEO,
τη διαχείριση ανακατευθύνσεων και την παρακολούθηση 404 ως σελίδες του περιβάλλοντος διαχείρισης· παραλείψτε το και διαχειρίζεστε
τα πάντα με [εντολές Artisan](/el/pro/headless).

## Απαιτήσεις {#requirements}

| | |
|---|---|
| PHP | 8.2–8.4 (Laravel 11)· 8.2–8.5 (Laravel 12)· 8.3–8.5 (Laravel 13) |
| Laravel | 11, 12 ή 13 |
| `rankbeam/laravel-seo` | ^3.20 (εγκαθίσταται αυτόματα από το Pro 2.40+) |
| `filament/filament` | **προαιρετικό** — 4.x ή 5.x, μόνο για το περιβάλλον διαχείρισης |
| `rankbeam/laravel-seo-filament` | **προαιρετικό** — ^1.11 όταν χρησιμοποιείτε τον επεξεργαστή SEO με Pro 2.36+ |

Ξεκινήστε με υπάρχουσα εφαρμογή Laravel και ρυθμισμένη βάση δεδομένων. Ολοκληρώστε πρώτα τη
[Γρήγορη εκκίνηση πυρήνα](/el/guide/quickstart), ώστε ένα μοντέλο να αποδίδει μεταδεδομένα και να υπάρχουν οι
πίνακες του πυρήνα. Μια άδεια Pro παρέχει τα παρακάτω διαπιστευτήρια Composer.

Για οπτικό παράδειγμα του αποτελέσματος, δείτε τη [σάρωση → διόρθωση → αναφορά](/el/pro/walkthrough).

## Εγκατάσταση του πακέτου {#install-the-package}

Το Pro διανέμεται μέσω ιδιωτικού αποθετηρίου Composer συνδεδεμένου με την
άδειά σας. Προσθέστε το αποθετήριο μία φορά και έπειτα εγκαταστήστε το πακέτο — το Composer θα
ζητήσει το email της άδειάς σας (όνομα χρήστη) και το κλειδί άδειας (κωδικός πρόσβασης):

Το Lemon Squeezy διαχειρίζεται την πληρωμή ως επίσημος πωλητής. Μετά την πληρωμή, η ιδιωτική σελίδα απόδειξης παρέχει το κλειδί λήψης και οδηγίες Composer. Χρησιμοποιήστε το email αγοράς ως όνομα χρήστη. Το Rankbeam φιλοξενεί το αποθετήριο πακέτων· δεν χρειάζεται λογαριασμός Anystack. Κρατήστε ιδιωτικά τον σύνδεσμο απόδειξης και το `auth.json`. Η πλήρης επιστροφή χρημάτων ανακαλεί μελλοντικές λήψεις και ενημερώσεις χωρίς να διακόπτει μια εγκατεστημένη εφαρμογή.

```bash
composer config repositories.rankbeam-pro composer https://blog.rankbeam.dev/composer
composer require rankbeam/laravel-seo-pro
```

::: details Μη διαδραστικός έλεγχος ταυτότητας Composer
Για CI ή μη διαδραστικά περιβάλλοντα, αποθηκεύστε τα διαπιστευτήρια εκ των προτέρων:

```bash
composer config http-basic.blog.rankbeam.dev you@example.com YOUR-LICENSE-KEY
```

:::

Έπειτα εκτελέστε το εργαλείο εγκατάστασης:

```bash
php artisan seo-pro:install
```

Το εργαλείο εγκατάστασης δημοσιεύει το `config/seo-pro.php` και τις μεταναστεύσεις Pro, εκτελεί
`migrate` και εκτυπώνει τα επόμενα βήματα. Οι πίνακες πυρήνα και Pro πρέπει τώρα να
υπάρχουν στη βάση δεδομένων της εφαρμογής σας.

::: details Χειροκίνητη εγκατάσταση και σημαίες εγκατάστασης
Οι μεταναστεύσεις Pro δημοσιεύονται στην εφαρμογή σας· δεν φορτώνονται αυτόματα από το
πακέτο. Τα αντίστοιχα χειροκίνητα βήματα είναι:

```bash
php artisan vendor:publish --tag=seo-pro-config
php artisan vendor:publish --tag=seo-pro-migrations
php artisan migrate
```

Το εργαλείο εγκατάστασης μπορεί να εκτελεστεί ξανά. Το `--no-migrate` δημοσιεύει αρχεία χωρίς να εκτελεί μεταναστεύσεις.
Χρησιμοποιήστε το `--force` μόνο όταν σκοπεύετε να αντικαταστήσετε δημοσιευμένα αρχεία, μαζί με
τις ρυθμίσεις σας.
:::

## Καταχώριση στόχων σάρωσης {#register-scan-targets}

Δηλώστε στον σαρωτή τι να σαρώσει σε έναν service provider — κλάσεις μοντέλων, ονομασμένες
διαδρομές ή τα πάντα στο [μητρώο χαρτών ιστοτόπου](/el/guide/sitemaps):

```php
use App\Models\Post;
use Rankbeam\Seo\Pro\Facades\SeoPro;

public function boot(): void
{
    SeoPro::targets()->register('posts', Post::class);
    // Optional: register named routes that exist in your app.
    // SeoPro::targets()->registerRoutes('static', ['home', 'pricing']);
    // Or discover targets from your registered sitemaps:
    // SeoPro::targets()->fromSitemaps();
}
```

Αντικαταστήστε το `Post` με δικό σας μοντέλο που χρησιμοποιεί `HasSEO`. Χρειάζεστε τουλάχιστον μία
εγγραφή για να δείτε αποτέλεσμα σάρωσης μοντέλου. Οι στόχοι διαδρομών πρέπει να ονομάζουν υπάρχουσες διαδρομές·
παραλείψτε αυτή την καταχώριση αν θέλετε να σαρώσετε μόνο μοντέλα.

## Επαλήθευση της εγκατάστασης {#verify-your-install}

Εκτελέστε τον έλεγχο ρυθμίσεων:

```bash
php artisan seo:doctor
```

Επιβεβαιώστε ότι υπάρχουν οι πίνακες πυρήνα και Pro, ότι η URL της εφαρμογής σας είναι σωστή
και ότι εμφανίζονται οι στόχοι σάρωσης. Ακολουθήστε τις αναφερόμενες διορθώσεις. Μια προειδοποίηση ουράς `sync`
είναι αναμενόμενη όσο δοκιμάζετε τις παρακάτω εντολές άμεσης εκτέλεσης· ρυθμίστε
worker πριν προγραμματίσετε σαρώσεις παραγωγής.

Οι κρίσιμες αποτυχίες επιστρέφουν μη μηδενικό κωδικό εξόδου· οι προειδοποιήσεις όχι.

## Εκτελέστε την πρώτη σας σάρωση {#five-minute-pro-tour}

```bash
php artisan seo-pro:scan --sync
php artisan seo-pro:scan-status
```

Η πρώτη εντολή ολοκληρώνει τη σάρωση άμεσα στην ίδια διεργασία, οπότε αυτός ο αρχικός έλεγχος δεν
χρειάζεται worker ουράς. Η δεύτερη δείχνει την τελευταία εκτέλεση και τα αποτελέσματά της. Αναμένετε
ολοκληρωμένη εκτέλεση με επεξεργασμένους τους καταχωρισμένους στόχους· διερευνήστε τυχόν
αποτυχημένους στόχους πριν θεωρήσετε ολοκληρωμένη τη σάρωση.

Διορθώστε ένα αναφερόμενο πεδίο, αποθηκεύστε το και εκτελέστε ξανά τη σάρωση. Η
[αναλυτική περιήγηση](/el/pro/walkthrough) το δείχνει με μια περιγραφή που λείπει και
αναφορά της αλλαγής. Η [τεχνική βαθμολογία](/el/pro/scoring) είναι διαγνωστικό αποτέλεσμα,
όχι πρόβλεψη κατάταξης.

## Χρήση χωρίς περιβάλλον διαχείρισης {#path-b-headless}

Η μηχανή είναι έτοιμη για χρήση χωρίς πάνελ. Οι [εντολές Artisan](/el/pro/headless)
σάς επιτρέπουν να σαρώνετε, να εξετάζετε ζητήματα, να δημιουργείτε ανακατευθύνσεις και αναφορές. Τα
middlewares ανακατευθύνσεων και 404 καταχωρίζονται αυτόματα από προεπιλογή· οι ρυθμίσεις τους
βρίσκονται στο `config/seo-pro.php`.

Για προγραμματισμένη εργασία, ακολουθήστε τη [Ρύθμιση παραγωγής](/el/pro/production) για να ρυθμίσετε
ουρές, workers, scheduler και διατήρηση δεδομένων.

## Προσθήκη πάνελ Filament (προαιρετικά) {#path-a-with-a-filament-panel}

Για υπάρχον πάνελ Filament 4 ή 5, καταχωρίστε το πρόσθετο Pro παρακάτω. Αν η
εφαρμογή σας δεν έχει ακόμη πάνελ, εγκαταστήστε πρώτα τα πακέτα διεπαφής και δημιουργήστε ένα:

```bash
composer require filament/filament rankbeam/laravel-seo-filament
php artisan filament:install --panels
php artisan make:filament-user
```

```php
use Rankbeam\Seo\Pro\Filament\SeoProPlugin;

public function panel(Panel $panel): Panel
{
    return $panel
        // ...
        ->plugin(SeoProPlugin::make());
}
```

Αυτό προσθέτει τον **πίνακα ελέγχου SEO** (ενέργεια σάρωσης όλων,
ζωντανή πρόοδο, λίστα ζητημάτων με επανάληψη σάρωσης σε ένα κλικ), τη **διαχείριση ανακατευθύνσεων**
και την **παρακολούθηση 404** με την ενέργεια *Δημιουργία ανακατεύθυνσης* σε ένα κλικ.
Το `rankbeam/laravel-seo-filament` προσθέτει επιπλέον στις φόρμες πόρων σας την
[ενότητα πεδίων SEO](/el/guide/filament).

## Αντιμετώπιση προβλημάτων {#troubleshooting}

| Αποτέλεσμα | Επόμενο βήμα |
|---|---|
| Το Composer απορρίπτει τα διαπιστευτήρια | Ελέγξτε το email άδειας και το κλειδί για το `blog.rankbeam.dev`. Κρατήστε τα διαπιστευτήρια εκτός ελέγχου εκδόσεων. |
| Το Doctor αναφέρει πίνακες που λείπουν | Ολοκληρώστε τη Γρήγορη εκκίνηση πυρήνα και έπειτα εκτελέστε `seo-pro:install` και `migrate` στην ίδια βάση με την εφαρμογή. |
| Μια σάρωση δεν επεξεργάζεται στόχους | Ελέγξτε την καταχώριση του provider και ότι το μοντέλο περιέχει εγγραφές. |
| Μια σάρωση σε ουρά παραμένει σε αναμονή | Εκκινήστε τον ρυθμισμένο worker ουράς ή χρησιμοποιήστε `--sync` για άμεσο έλεγχο. |
| Ένας στόχος αποτυγχάνει | Ελέγξτε τις λεπτομέρειες εκτέλεσης, τα ονόματα διαδρομών και την URL εφαρμογής πριν σαρώσετε ξανά. |
| Ο πίνακας ελέγχου λείπει | Καταχωρίστε το `SeoProPlugin` στο πάνελ που πράγματι χρησιμοποιείτε και ελέγξτε τα gates πρόσβασης. |

Δείτε τη [Ρύθμιση παραγωγής](/el/pro/production) για ανάκαμψη workers και συνεχή λειτουργία.
