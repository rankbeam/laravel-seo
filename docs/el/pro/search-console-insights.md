# Αναλύσεις Search Console {#search-console-insights}

Πέντε αναφορές υπολογισμένες από τα δικά σας δεδομένα Search Console: ερωτήματα σε επιλεγμένο
εύρος θέσεων, υποψήφιες βελτιώσεις CTR, επικαλυπτόμενα αποτελέσματα ερωτημάτων/σελίδων, ομάδες
ερωτημάτων και μεταβολές περιόδου. Τρεις χρησιμοποιούν συγχρονισμένο ιστορικό· δύο μοιράζονται ζωντανό
αίτημα με cache. Καλύπτουν αυτές τις συγκεκριμένες αναλύσεις, όχι το πλήρες σύνολο δεδομένων ή τις δυνατότητες
μιας πλατφόρμας λέξεων-κλειδιών τρίτου.

Βασίζεται στην [ενσωμάτωση Search Console μόνο για ανάγνωση](/el/pro/search-console) και
στον συγχρονισμό ιστορικού της. Αν το `seo-pro:gsc-sync` εκείνης της σελίδας εκτελείται ήδη, αυτές οι
αναλύσεις λειτουργούν με **μηδενικό επιπλέον κόστος API** για τρεις από τις πέντε επιφάνειες.

::: tip Προαπαιτούμενο
Οι τρεις επιφάνειες *στιγμιοτύπου* διαβάζουν το αποθηκευμένο ιστορικό `seo_gsc_metrics`, οπότε
προγραμματίστε πρώτα το `seo-pro:gsc-sync` (δείτε το [Search Console → ιστορικό](/el/pro/search-console)).
Όσο περισσότερες ημέρες έχετε συγχρονίσει, τόσο βαθύτερα φτάνει η σύγκριση τάσεων.
:::

## Οι πέντε επιφάνειες {#the-five-surfaces}

### 1. Λέξεις-κλειδιά κοντά στις πρώτες θέσεις {#_1-striking-distance-keywords}

Ερωτήματα των οποίων η **μέση θέση, σταθμισμένη με τις εμφανίσεις, βρίσκεται στο 5–20**, ταξινομημένα βάσει
εμφανίσεων. Χρησιμοποιήστε τα για να εξετάσετε συνάφεια και εσωτερικούς συνδέσμους· αυτό το εύρος δεν
αποδεικνύει ότι μια μικρή αλλαγή θα μετακινήσει ένα ερώτημα στην πρώτη σελίδα.

### 2. Ευκαιρίες CTR {#_2-ctr-opportunities}

Ερωτήματα που **κατατάσσονται καλά αλλά δέχονται κλικ κάτω από το αναμενόμενο ποσοστό** για τη
θέση τους. Το πραγματικό CTR κάθε ερωτήματος συγκρίνεται με συνδυαστική κλαδική
καμπύλη CTR ανά θέση· όσα βρίσκονται πολύ κάτω από το αναμενόμενο ποσοστό — με πραγματικές
εμφανίσεις — είναι **υποψήφια για επανεγγραφή τίτλου/περιγραφής**, ταξινομημένα βάσει των
εκτιμώμενων *χαμένων κλικ*. Αυτή η λίστα είναι η
φυσική είσοδος για το [εργαλείο προτάσεων μεταδεδομένων AI](/el/pro/ai-assist): σας δίνει τα
συγκεκριμένα ερωτήματα για τα οποία αξίζει να επανεξετάσετε το κείμενο.

### 3. Κανιβαλισμός {#_3-cannibalization}

Ερωτήματα όπου **εμφανίζονται δύο ή περισσότερες URL σας** για τον ίδιο όρο. Η επικάλυψη δεν είναι
αναγκαστικά επιβλαβής: εξετάστε αν οι σελίδες εξυπηρετούν διαφορετικές προθέσεις πριν
τις ενοποιήσετε ή τις διαφοροποιήσετε.

### 4. Ομάδες ερωτημάτων {#_4-query-clusters}

Τα **ερωτήματα για τα οποία κατατάσσεται πραγματικά κάθε σελίδα**, ομαδοποιημένα ανά σελίδα — το πραγματικό
θεματικό αποτύπωμά της στα μάτια του Google. Χρήσιμο για να εντοπίσετε σελίδα που απομακρύνεται
από το επιδιωκόμενο θέμα της ή κατατάσσεται αθόρυβα για πολύτιμο όρο που
δεν είχατε στοχεύσει.

### 5. Τάση σε σχέση με την προηγούμενη περίοδο {#_5-trend-vs-previous-period}

Οι **μεγαλύτερες μεταβολές** — κλικ, εμφανίσεις, θέση και CTR — για το τρέχον
παράθυρο σε σύγκριση με το αμέσως προηγούμενο ίσης διάρκειας. Η θέση συγκρίνεται μόνο
όταν ένα ερώτημα είχε κίνηση και στις δύο περιόδους (δεν υπάρχει βάση σύγκρισης για ολοκαίνουργιο
ερώτημα ή για ερώτημα που εξαφανίστηκε πλήρως).

## Από πού προέρχονται οι αριθμοί: ζωντανά δεδομένα και στιγμιότυπα {#where-the-numbers-come-from-live-vs-snapshot}

Κάθε επιφάνεια διαβάζει την πηγή που απαντά σωστά με το μικρότερο κόστος.
Το αποθηκευμένο ιστορικό δεν μπορεί να ανασυνθέσει ποιο **ερώτημα** συνδυάστηκε με ποια
**σελίδα** (αποθηκεύει κάθε διάσταση ξεχωριστά), οπότε οι δύο επιφάνειες που χρειάζονται
αυτό το ζεύγος είναι οι μόνες που ανακτούν ζωντανά δεδομένα — και **μοιράζονται ένα μόνο αίτημα
με cache**.

| Επιφάνεια | Πηγή | Αιτία |
|---|---|---|
| Κοντά στις πρώτες θέσεις | **Τοπικό στιγμιότυπο** | χρειάζεται θέση και εμφανίσεις ανά ερώτημα, ήδη στο συγχρονισμένο ιστορικό σας — χωρίς κόστος API |
| Ευκαιρίες CTR | **Τοπικό στιγμιότυπο** | τα ίδια δικά σας δεδομένα· η καμπύλη αναμενόμενου CTR είναι στατικό σημείο αναφοράς, όχι εξωτερική αναζήτηση |
| Διαφορές τάσης | **Τοπικό στιγμιότυπο** | χρειάζεται πραγματικό ιστορικό ανά ημέρα, ακριβώς αυτό που αποθηκεύει ο συγχρονισμός |
| Κανιβαλισμός | **Ζωντανά** (ερώτημα × σελίδα) | ο συνδυασμός ερωτήματος→σελίδας δεν αποθηκεύεται και η αποθήκευση κάθε ζεύγους θα πολλαπλασίαζε τον χώρο σας |
| Ομάδες ερωτημάτων | **Ζωντανά** — *μοιράζεται την ανάκτηση της επιφάνειας 3* | τα ίδια δεδομένα ζευγών, ομαδοποιημένα ανά σελίδα αντί ανά ερώτημα |

Επομένως, μια επίσκεψη στη σελίδα αναλύσεων κοστίζει **το πολύ ένα** αίτημα Search Analytics,
που αποθηκεύεται σε cache για `search_console.cache_ttl` δευτερόλεπτα. Οι επιφάνειες ζευγών χρησιμοποιούν ζωντανά δεδομένα
σκόπιμα: ο κανιβαλισμός και η ομαδοποίηση είναι ερωτήματα *μιας χρονικής στιγμής*, όπου
θέλετε την τρέχουσα εικόνα, και η κοινή cache περιορίζει τα επαναλαμβανόμενα αιτήματα. Η ανανέωση token μπορεί να απαιτήσει
πρόσθετο αίτημα ελέγχου ταυτότητας και τα όρια χρήσης του Google εξακολουθούν να ισχύουν. Οι επιφάνειες στιγμιοτύπου δεν χρησιμοποιούν ποτέ το δίκτυο.

## Στον πίνακα ελέγχου {#in-the-dashboard}

Με εγκατεστημένο το πρόσθετο Filament, οι **Πληροφορίες Search Console** εμφανίζονται στην ομάδα πλοήγησης
*SEO* (μόνο όταν είναι ενεργή η ενσωμάτωση). Είναι αυστηρά μόνο για ανάγνωση:
κάθε επιφάνεια αποδίδεται ως ενότητα, οι επιφάνειες στιγμιοτύπου εμφανίζουν υπόδειξη συγχρονισμού
ιστορικού όταν είναι κενές και μια αποτυχημένη ζωντανή ανάκτηση για τις επιφάνειες ζευγών εμφανίζει
ενσωματωμένη ειδοποίηση με καθαρισμένο περιεχόμενο — ποτέ μπλοκαρισμένη σελίδα.

## Ρυθμίσεις {#configuration}

Όλα βρίσκονται στο `search_console.insights` του `config/seo-pro.php`. Οι
προεπιλογές είναι λογικές· προσαρμόστε τα κατώφλια στην κλίμακα του ιστοτόπου σας.

```php
'search_console' => [
    // ...
    'insights' => [
        // Rolling window (days) the snapshot surfaces aggregate over,
        // anchored to the latest synced day.
        'window_days' => 28,

        // Max rows a surface returns to its panel section.
        'max_rows' => 50,

        // (1) Striking distance: impression-weighted position in [min,max]
        // with at least this many impressions.
        'striking_distance' => [
            'min_position' => 5.0,
            'max_position' => 20.0,
            'min_impressions' => 30,
        ],

        // (2) CTR opportunity: queries ranking at/above max_position, with at
        // least min_impressions, whose CTR is at least min_gap_ratio below the
        // expected curve.
        'ctr_opportunity' => [
            'max_position' => 10.0,
            'min_impressions' => 50,
            'min_gap_ratio' => 0.30,
        ],

        // Optional override of the expected CTR-by-position curve
        // (position => percent). null uses the built-in blended curve.
        'ctr_curve' => null,

        // (3) Cannibalization: a query with this many URLs each drawing at
        // least min_impressions.
        'cannibalization' => [
            'min_urls' => 2,
            'min_impressions' => 10,
        ],

        // (4) Query clustering: queries per page above min_impressions.
        'clustering' => [
            'min_impressions' => 10,
            'max_queries_per_page' => 15,
        ],

        // (5) Trend deltas: surface queries with at least this many
        // impressions in either period.
        'trend' => [
            'min_impressions' => 20,
        ],

        // The shared live (query,page) fetch for surfaces 3 + 4.
        'pair_days' => 28,
        'pair_row_limit' => 5000,
    ],
],
```

::: info Καμπύλη αναμενόμενου CTR
Η καμπύλη ευκαιριών CTR είναι **ευρετική**, συνδυασμένη από δημοσιευμένους μέσους όρους οργανικού
CTR ανά θέση — είναι μέτρο σύγκρισης, όχι ισχυρισμός για τον συγκεκριμένο
ιστότοπό σας. Ένα ερώτημα που επισημαίνεται εδώ είναι *υποψήφιο προς έλεγχο*, όχι αποδεδειγμένο ελάττωμα. Αν
έχετε δική σας μετρημένη καμπύλη, βάλτε τη στο `insights.ctr_curve` ως
αντιστοίχιση `position => percent`.
:::
